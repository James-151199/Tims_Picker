TIMS PICKER

If you don't want to use it, you can look at the calculation I make at line 189 of tims_test.py

But if you want to use it see below

1. To use the tim's picker fill out the text file Tims_Picks with the players.
One name per line so:

Leon Draisaitl
Zach Hyman
Evander Kane
...

2. Once you've done that, press the windows key and type "cmd" to open the command prompt

3. Navigate to the folder where you have the Tim's Picker by using:

- cd "directory name" - to go into a directory
- cd .. - to go back one directory
- dir - to see what folders are in the directory

4. run this command to get the nhl client "pip install nhl-api-py"

5. type "python3 Tims_test.py" and wait a bit, the players likelyhood to score, total goals, goals past 5 and # gamesplayed should show up.
